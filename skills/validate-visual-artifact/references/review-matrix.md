# Visual review matrix

For every finding record route/section, state, viewport, severity, evidence, impact, and smallest fix.

## Structure and content

- One clear primary message/job; factual labels and no invented claims.
- Hierarchy, reading order, line length, density, alignment, and spacing rhythm.
- Long content, localization, unknown/zero values, and honest empty/error guidance.

## Interaction

- Direct and visible navigation; all primary controls; refresh, return, reset, and recovery.
- Keyboard order, visible focus, dialogs, sticky regions, reduced motion, and zoom.
- Loading, empty, blocked, error, success, and partial states.

## Rendering

- Named desktop/presentation/tablet/mobile widths; overflow, clipping, reflow, and touch targets.
- Typography availability/fallbacks, contrast, icons, charts/diagrams, print, and fullscreen.
- Console warnings/errors, failed resources, broken links, and stale generated data.

Visual inspection does not replace semantic HTML, automated accessibility testing, business validation,
security review, or independent acceptance verification.
