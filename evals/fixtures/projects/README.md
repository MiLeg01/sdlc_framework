# Representative evaluation projects

This portfolio intentionally stays small. Each project separates executor-visible `input/` from validator-only
`golden/` expectations. Scenario contracts may expose only files listed under `source_artifacts`; paths below a
project's `golden/` directory are prohibited executor inputs.

The portfolio covers mixed-language legacy modernization, OpenSpec/TDD development, deterministic local
research, dashboard completeness and visual states, and synthetic Austrian public-sector delivery. Existing
lower-level fixtures and canonical assets are reused when they already express the required behavior.
