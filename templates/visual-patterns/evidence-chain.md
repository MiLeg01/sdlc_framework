# Evidence chain pattern

- Best use: showing how sources support findings, implications, decisions, or claims.
- Avoid: using a linear chain when evidence conflicts, branches, or has unresolved gaps.
- Capacity: 3-5 lifecycle stages with bounded evidence nodes per stage.
- Interaction: optional provenance details and contradiction or gap highlighting.
- Responsive: collapse into ordered source-finding-implication records.
- Accessibility: expose every edge and status in text; never make line direction the only explanation.
