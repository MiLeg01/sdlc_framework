## Agent Commons working agreements

- Verify significant claims before declaring completion; state validation limits.
- Separate evidence, interpretation, proposals, assumptions, conflicts, and unknowns.
- Preserve unrelated user work and explicit protected or read-only paths.
- Prefer deterministic tools for enumeration, generation, and consistency checks.
- Use specialized workflows or roles only when they materially improve quality or isolation.
- Keep project and client-specific knowledge inside the project, never in global commons.
- For substantial projects, load compact project memory before repeating analysis and retrieve only the domains or entities needed for the current task.
- Keep generated dashboards synchronized with canonical project state when a project uses one.
- Follow the repository or generated project `AGENTS.md` Git policy: meaningful subjects, no Conventional
  Commit prefixes, reliable ticket prefixes only, and no co-author or agent-attribution trailers.
