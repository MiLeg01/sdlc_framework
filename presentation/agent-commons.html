What is what?

Plain-language building blocks, each with one job.

The repository separates reusable methods, specialist roles, automation, structures, composition, runtime bridges, and evals. Catalogs hold stable IDs and relationships; installation exposes them safely; this presentation renders current facts.

SkillA reusable method—like a playbook for legacy analysis, TDD, diagrams, research, or dashboards.HOW should this work be done?
AgentA bounded specialist—like a colleague who independently investigates or validates one responsibility.WHO should own this perspective?
ToolDeterministic automation for inventory, counting, rendering, validation, merging, and other exact work.What should a script calculate instead of an LLM guessing?
ArchetypeAn initialization-time project recipe that selects and prioritizes existing capabilities. It is recorded as configuration; it is not executed at runtime.Which capability set fits this project family?
OverlayA reusable cross-cutting rule such as branding, bilingual delivery, traceability, or a living dashboard.What behavior applies across project types?
AdapterThe bridge that exposes the same runtime-neutral method to Codex, Claude Code, Cline, or OpenCode.How does this AI tool discover it?
EvalA behavior test that checks the initializer, analysis depth, dashboards, TDD, and other promises still hold.How do we know the method still works?
TemplateA reusable output shape—structure without pretending that structure itself supplies engineering judgment.What should the result look like?

Install once. Initialize the project you actually have.

Contribution: review-for-commons
“I created something useful.” What now?

          
Run review-for-commons at a meaningful milestone. It writes a sanitized project-local proposal; it does not move code, install anything, or mutate Agent Commons.

        

        

          
01 / REUSEUseful beyond this project?Require proven value that survives removal of client and application details.

          
02 / OVERLAPAlready covered?Compare responsibility, workflow, outputs, validation, and routing—not names alone.

          
03 / SAFETYSafe to generalize?Remove credentials, private paths, business rules, source excerpts, identities, and proprietary assumptions.

          
04 / ABSTRACTIONWhat should it become?Skill, agent, tool, template, archetype, overlay, adapter, eval—or intentionally project-local.

review-for-commons — evidence and semantic comparison

          
Sanitized proposal — no Commons mutation

          
User decision — select an exact candidate or keep it local

        

        

          
COMPARISONEXACT · OVERLAP · EXTENSIONOr REPLACEMENT, NEW, and PROJECT_LOCAL—based on actual Commons behavior.

          
PROJECT FINDINGPOTENTIALLY_REUSABLE · VARIATIONOr PROJECT_LOCAL, LOCAL_DUPLICATE, and REJECTED when the evidence does not justify promotion.

Contribution: promote-to-commons
Generalize the experience. Do not copy the project.

          
Promotion begins only after an explicit candidate selection. The workflow independently revalidates the evidence and may still block or decline the change.

        

        

          

            

              
SELECT
Bind the exact candidateApproval applies only to the named capability—not an entire review report.

              
REVALIDATE
Challenge reuse and overlapInspect primary evidence, maturity, confidentiality, licensing, routing, and runtime neutrality.

              
GENERALIZE
Extract the reusable methodRemove project assumptions; create, update, merge, split, deprecate, or deliberately do not promote.

              
VALIDATE
Protect the company assetAdd evals, synchronize catalogs and adapters, refresh generated data, run gates, then commit.

            

            
User approval authorizes revalidation. It never guarantees inclusion.

            
BLOCK CONFIDENTIALBLOCK UNKNOWN LICENSEBLOCK DUPLICATEBLOCK WEAK EVIDENCE
