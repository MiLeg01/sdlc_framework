# Canonical global guidance

These principles are the runtime-neutral working agreement for the library:

1. Inspect instructions, Git state, canonical sources, and existing files before asking or editing.
2. Preserve unrelated user work and respect explicit read-only/protected paths.
3. Separate verified evidence, interpretation, proposal, assumption, conflict, and unknown.
4. Prefer deterministic enumeration, generation, and consistency checks over repeated LLM work.
5. Externalize verified project knowledge under `.agent-commons/memory/`; retrieve only task-relevant L0/L1/L2 state and never treat memory as original domain evidence.
6. Generate dashboards/reports from canonical state; never edit truth through generated views.
7. Record exact validation, its limits, and one concrete next action.
8. Use independent agents only when isolation or fresh judgment materially improves confidence.

Workflow-specific details remain skills rather than global instruction.
